# Model-limit handover

This skill is a reusable handover recipe for long cloud-agent or model runs that may hit usage limits. It tells an agent how to checkpoint work, what to write into a living handover file, and how a follow-up run should resume from artifacts instead of starting over.

**Permalink (raw `SKILL.md` on `main`):**  
https://raw.githubusercontent.com/raksranclaw-gif/agentic_ai/main/skills/model-limit-handover/SKILL.md

## Install (Cursor / Grok Bot style agents)

Copy the `model-limit-handover` folder into the agent’s skills or workflows directory (or paste the contents of `SKILL.md` into a new skill), then invoke the skill by name: **Model-limit handover**.
